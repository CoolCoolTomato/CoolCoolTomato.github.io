数据类型

类型说明
Integer一个整数
String (size)有长度限制的字符串
Text些较长的 unicode 文本
DateTime表示为 Python datetime 对象的 时间和日期
Float存储浮点值
Boolean存储布尔值
PickleType存储为一个持久化的 Python 对象
LargeBinary存储一个任意大的二进制数据

配置

配置建作用
SQLALCHEMY_DATABASE_URI连接数据库的URI
SQLALCHEMY_BINDS一个映射绑定 (bind) 键到 SQLAlchemy 连接 URIs 的字典，用于连接多个数据库
SQLALCHEMY_ECHO记录发到标准输出的所有语句
SQLALCHEMY_RECORD_QUERIES显式地禁用或者启用查询记录
SQLALCHEMY_NATIVE_UNICODE显式地禁用支持原生的 unicode
SQLALCHEMY_POOL_SIZE数据库连接池的大小
SQLALCHEMY_POOL_TIMEOUT指定数据库连接池的超时时间
SQLALCHEMY_POOL_RECYCLE自动回收连接的秒数
SQLALCHEMY_MAX_OVERFLOW控制在连接池达到最大值后可以创建的连接数
SQLALCHEMY_TRACK_MODIFICATIONS追踪对象的修改并且发送信号，默认为True

URI格式

Postgres

postgresql://user:password@localhost/database

Mysql

mysql://user:password@localhost/database

Oracle

oracle://user:password@127.0.0.1:1521/database

SQLite

sqlite:////absolute/path/to/database.db
